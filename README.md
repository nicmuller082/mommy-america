# Mommy America

Temporary marketing site for home cleaning in Cinco Ranch, Katy, Richmond, and Sugar Land.

This repo is separate from `nuroburst` and `nuroburst-www`. Nothing in those repos was changed.

Login, accounts, and the booking calendar are not in this version. The quote form prices a visit and saves the request in the browser only.

## Render

This repo does not appear in Render by itself. In the Render dashboard: New, Blueprint, connect `nicmuller082/mommy-america`. `render.yaml` publishes the site root as a static site named `mommy-america`. It does not change `nuroburst` or `nuroburst-www`.


## Pages

Open `index.html`. Plans, the rate card, add-ons, and a working quote are on the one page.
